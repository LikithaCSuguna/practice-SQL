# SQL Practice

A curated collection of SQL practice problems covering database fundamentals, querying, joins, aggregation, window functions, and interview-focused challenges to strengthen SQL skills for technical interviews.

## About

This repository contains my structured SQL practice journey. It includes solutions to fundamental SQL concepts as well as popular interview questions from platforms like LeetCode and similar coding websites.

The repository is organized in a progressive order, starting with database basics and gradually moving to advanced SQL queries and real-world problem-solving.

## Who Is This Repository For?

- Students learning SQL
- Beginners practicing database concepts
- Developers preparing for technical interviews
- Anyone looking to improve SQL problem-solving skills

# How to Use

1. Clone the repository.

```bash
git clone https://github.com/LikithaCSuguna/practice-SQL.git
```

2. Open any `.sql` file.

3. Execute the queries using your preferred SQL database such as:

- MySQL
- PostgreSQL
- SQL Server
- SQLite

4. Compare your solutions and practice different approaches.
